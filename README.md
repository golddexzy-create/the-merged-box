# The Merged Box

A playable old-time radio booth.

Four cabinets from 1931 to 1956 sit on one floor that is both a newsroom and a business desk. Power the box, tune a single set, or merge all four into one groove while the cameras, the copy, and the floor protocols keep moving behind it.

## Cabinets

| Year | Shape | Call | What it is |
| --- | --- | --- | --- |
| 1931 | Cathedral | WMBX | Parlor organ under a slow swing |
| 1936 | Tombstone | KTMB | The evening bulletin |
| 1947 | Bakelite | WBZT | Business wire and teletype |
| 1956 | Console | KGRV | The lowboy groove |

**Merge the boxes** locks them into one station, WGRV.

## Run it

```bash
npm install
npm run dev
```

Open the app, press **Power up**, then tune or merge. Sound starts on that click. The browser will not play audio until you do.
